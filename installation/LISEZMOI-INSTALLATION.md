# Installer Mon Centre Social

Utilisez **Mon-Centre-Social-1.0.0-rc1-Setup-x64.exe**.

L assistant Windows installe tous les composants sans PowerShell ni modification
manuelle du PATH. Le dossier confidentiel est reserve a la direction / DSI.

Guide complet : [Installation Windows](../docs/GUIDE-WINDOWS.md).
Construction depuis les sources : [Distribution Windows](../desktop/README.md).

Les anciens scripts Installer.ps1 / Desinstaller.ps1 ne constituent plus le
parcours de distribution. Desinstaller.ps1 ne doit pas etre utilise pour retirer
la nouvelle version : utiliser Applications installees dans les Parametres Windows.
