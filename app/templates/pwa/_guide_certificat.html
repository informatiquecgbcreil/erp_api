{# Faire confiance au certificat du centre, appareil par appareil. Inclus par la page d'installation (pour le collègue, sur son appareil) et par Administration > Connecter un appareil. Attend « connexion » (app/services/connexion_appareils.py) avec un certificat présent. #} {% set cert = connexion.certificat %}

La première fois, l'appareil affiche une alerte de sécurité (« Votre connexion n'est pas privée », « Non sécurisé »). C'est attendu : il ne connaît pas encore le certificat du centre, qui garantit que vous parlez bien au serveur du centre. Installez-le une seule fois par appareil et l'alerte disparaît.

Par prudence, faites-le sur le wifi du centre, jamais sur un réseau public, et comparez l'empreinte quand l'appareil l'affiche : {{ cert.empreinte_windows }} (empreinte « SHA-1 »). Si elle diffère, n'installez rien et prévenez la direction.

{% if not cert.bride %}

⚠️ Ce certificat vient d'une installation ancienne : il n'est pas limité aux adresses du centre. Installez-le seulement sur les appareils du centre, pas sur des téléphones personnels. Pour ceux-là, un certificat reconnu (nom public) évite toute installation : voir le guide d'installation Windows.

{% endif %}

⬇️ Télécharger le certificat du centre

💻 Ordinateur Windows (Edge, Chrome)
  1. Téléchargez le certificat, puis ouvrez le fichier Certificat-du-centre.cer.
  2. Cliquez sur « Installer le certificat… », choisissez « Utilisateur actuel », puis « Suivant ».
  3. Cochez « Placer tous les certificats dans le magasin suivant », cliquez sur « Parcourir… » et choisissez « Autorités de certification racines de confiance ». Puis « Suivant » et « Terminer ».
  4. Windows demande confirmation et affiche une « empreinte numérique (sha1) ». Elle doit être identique à :
    {{ cert.empreinte_windows }}
    Si c'est le cas, cliquez sur « Oui ». Sinon, cliquez sur « Non » et prévenez la direction.
  5. Fermez complètement le navigateur, puis rouvrez l'adresse de l'application.
📱 Téléphone ou tablette Android
  1. Téléchargez le certificat : le fichier arrive dans « Téléchargements ».
  2. Ouvrez les Paramètres et tapez « certificat » dans la recherche, puis choisissez « Certificat CA » (selon les modèles : Sécurité → Paramètres avancés → Chiffrement et identifiants → Installer un certificat → Certificat CA).
  3. Touchez « Installer quand même », confirmez avec le code de l'appareil, puis choisissez le fichier Certificat-du-centre.cer.
  4. Android affiche ensuite « Le réseau peut être surveillé » : c'est normal, il parle du certificat du centre. Rouvrez l'adresse de l'application dans Chrome.
📱 iPhone ou iPad
  1. Dans Safari, touchez « Télécharger le certificat du centre », puis « Autoriser ».
  2. Ouvrez Réglages → « Profil téléchargé » (tout en haut). Touchez « Plus de détails » puis le certificat : son empreinte SHA-1 doit être celle indiquée plus haut. Revenez en arrière, touchez « Installer » et entrez le code de l'appareil.
  3. Puis Réglages → Général → Informations → tout en bas « Réglages des certificats » : activez le certificat {{ cert.nom }}.
  4. Revenez dans Safari et rouvrez l'adresse de l'application.

Certificat valable jusqu'au {{ cert.expire_le.strftime('%d/%m/%Y') }}. {% if cert.bride %}Il ne vaut que pour les adresses du centre : il ne permet pas d'usurper un autre site.{% endif %}
