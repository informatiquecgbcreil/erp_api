🎓 Mode entraînement

Pour découvrir l'application et former l'équipe sans risque : la base est remplie de fausses données (habitants, activités, séances, présences, adhésions). Essayez tout, puis effacez tout d'un clic avant de saisir vos vraies données.

{% if actif %}

L'entraînement est en cours

Depuis le {{ depuis.strftime('%d/%m/%Y à %H:%M') if depuis else '—' }} (heure UTC). Le bandeau orange le rappelle sur toutes les pages.

  • Reçus fiscaux et factures de location sont indisponibles : leur numérotation officielle ne recule jamais.
  • Tout ce qui est créé pendant l'entraînement sera effacé, y compris vos propres essais.
  • Seront gardés : les comptes, les réglages (nom, logo, territoire, modules), les secteurs, les quartiers, les salles et les tarifs.

Tout effacer et passer en mode réel

Une sauvegarde complète est faite juste avant. Si elle échoue, rien n'est effacé.

{% elif donnees_reelles %}

Indisponible sur cette base

Le mode entraînement ne s'active que sur une base sans données réelles, pour ne jamais mélanger vraies et fausses données. Cette base contient déjà {{ donnees_reelles|join(', ') }}.

{% else %}

Activer le mode entraînement

La base est vierge : vous pouvez la remplir de données d'exemple pour vous entraîner.

  • Une vingtaine d'habitants, trois activités, six semaines de séances avec leurs présences, des adhésions réglées en caisse et d'autres à relancer.
  • Les habitants prennent les quartiers déjà réglés pour votre ville siège : réglez votre territoire d'abord (Administration > Nom et logo) pour un exemple plus parlant.
  • Un bandeau orange « MODE ENTRAÎNEMENT » s'affichera sur toutes les pages jusqu'au passage en mode réel.
