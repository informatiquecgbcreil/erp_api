📱 Connecter un appareil

Une tablette pour l'émargement, le PC ou le téléphone d'un collègue : scannez le bon QR code avec l'appareil, connecté au wifi du centre.

{% if connexion.application_locale_seulement or connexion.kiosque_local_seulement %}

⚠️ Les autres appareils ne peuvent pas joindre cette adresse

L'application répond à une adresse qui ne fonctionne que sur le serveur lui-même ({{ connexion.adresse_installation if connexion.application_locale_seulement else connexion.adresse_kiosque }}) : les QR codes ci-dessous ne mèneront nulle part depuis une tablette ou un téléphone.

Sur le serveur Windows, relancez « Configurer Mon Centre Social » depuis le menu Démarrer et choisissez l'accès depuis les autres postes du réseau. Hors installateur Windows, l'adresse se règle avec ERP_PUBLIC_BASE_URL.

{% endif %}

🖐️ Une tablette pour l'émargement des participants

Ouvre le pointage public : les participants émargent eux-mêmes, sans accès au reste de l'application. Aucun certificat à installer, aucune alerte.

{{ connexion.adresse_kiosque }}

Sur la tablette, ajoutez la page à l'écran d'accueil pour la retrouver d'un geste. Pour une séance précise, utilisez plutôt le QR code de sa feuille d'émargement (valable 12 heures). {% if connexion.hors_les_murs %}Ce lien fonctionne aussi hors du centre (accès « hors les murs »).{% endif %}

💻 Le PC ou le téléphone d'un collègue

Ouvre la page « Installer l'application » : le collègue y trouve le mode d'emploi de son appareil, puis se connecte avec son propre compte (Administration > Équipe).

{{ connexion.adresse_installation }}

🔒 L'alerte de sécurité

{% if connexion.nom_public %}

✅ L'application utilise un certificat reconnu ({{ connexion.nom_public }}) : aucun appareil n'a de certificat à installer, aucune alerte ne s'affiche.

{% elif not connexion.https %}

L'adresse de l'application n'est pas sécurisée (http://) : pas d'alerte, mais les téléphones ne pourront pas l'installer comme une appli, et les échanges ne sont pas chiffrés. L'installateur Windows en mode réseau règle cela.

{% elif connexion.certificat %} {% include "pwa/_guide_certificat.html" %}

Le collègue retrouve ces explications sur la page d'installation, sous « Une alerte de sécurité s'affiche ? ».

{% else %}

Le certificat du centre n'a pas été trouvé sur ce serveur. Sur le serveur Windows, il se trouve dans C:\ProgramData\MonCentreSocial\public\Certificat-du-centre.cer ; sinon, demandez-le à la personne qui a installé le serveur.

{% endif %}
